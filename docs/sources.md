# Sourced Third-Party Models

Tracks any model in this project not designed from scratch here — same
convention as `versus-chess/matchups/*/sources.md`. A model is **repo-eligible**
(its file may be committed into this repo) only if its license explicitly
allows redistribution/remixing. Otherwise it stays link-only.

| Module | Model | Author | URL | License | Repo-eligible |
|---|---|---|---|---|---|
| Module 6 — Handle Dock | Miniature painting handle: "The Chuck V2" | Ashwood | https://makerworld.com/en/models/708184-miniature-painting-handle-the-chuck-v2 | Standard Digital File License (MakerWorld) | No — personal printing only, not redistributable. Link only; do not commit the STL. |

**Verification note (2026-09-09):** Standard Digital File License forbids
remixing/redistributing per MakerWorld's own license terms (see local tooling
memory on license verification). Compared against MakerWorld's next-best
alternative by download count — "Print-in-Place 3-Jaw Chuck for Painting
Miniatures" (6,476 downloads / 4,227 likes) vs. Chuck V2's 27,981 downloads /
6,898 likes — before confirming Chuck V2 as the pick, not just accepting the
first link provided.
